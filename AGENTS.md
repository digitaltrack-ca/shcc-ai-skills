# SHCC AI Skills — Agent Instructions

This repository stores reusable Solano Hispanic Chamber of Commerce operating skills.

## Structure
- `skills/<skill-name>/SKILL.md` — independent workflow instructions.
- Shared standards may be added later, but do not force one event type's process onto another.

## How to use
Read the relevant skill before carrying out its workflow. For a recurring **Banda Lonchera** promotion, use `skills/banda-lonchera-promotion/SKILL.md`.

## Standards
- Verify each month's event facts from current sources; never reuse previous dates, venues, speakers or prices.
- SHCC serves Solano County; writing is community-oriented, clear and practical.
- Default staff instructions: Sumeen (social posts) in English; Vivian (event page, email and SMS) in Spanish, subject to user changes.
- Don't create duplicate Drive folders, Docs, pages, or Asana tasks.
- Honor staged requests; don't create later deliverables before requested.
- Use the live event-page link only when published.
- Staff have reasonable autonomy to execute approved workflows and adapt copy; escalate true blockers rather than routine creative variations.
- Skills are instructions, not proof that a connected tool is available or that an action was completed.
