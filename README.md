# SHCC AI Skills

Reusable AI skills for the Solano Hispanic Chamber of Commerce (SHCC).

This repository follows the same skills-folder convention as [DigitalTrack AI Skills](https://github.com/digitaltrack-ca/digitaltrack-ai-skills), with separate workflows for different Chamber event types.

## Skills

| Skill | Purpose |
| --- | --- |
| [Banda Lonchera Promotion](skills/banda-lonchera-promotion/SKILL.md) | Prepare and coordinate monthly Banda Lonchera event-page, social media, email, SMS, Google Drive and Asana work |

Future skills: mixers, workshops, ribbon cuttings and other SHCC workflows.

## Usage

Use natural language such as **"Prepare next month's Banda Lonchera promotion"**. An agent with access to this repository should read the corresponding `SKILL.md` and use the current flyer and event details before proceeding.

See [AGENTS.md](AGENTS.md) for repository-level instructions. The skill describes a process; an agent still requires access to Google Drive, Asana and other relevant tools to execute it.
